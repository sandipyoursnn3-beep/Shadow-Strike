SHADOW STRIKE - mobile (landscape) build
=========================================
PLAY NOW (no APK): open www/index.html in Chrome on your phone -> menu -> "Add to Home screen".

GET THE APK (free, ~5 minutes, no installs on your PC):
 1. Create a free account at github.com and make a new repository (any name).
 2. Upload everything in this folder (keep the .github folder and www folder as they are).
    Tip: on the repo page choose "Add file > Upload files" and drag the unzipped contents in.
 3. Open the "Actions" tab -> "Build APK" -> "Run workflow".
 4. When it turns green (3-6 min) open the run -> download "ShadowStrike-apk" (a zip containing app-debug.apk).
 5. Send app-debug.apk to your phone and install it (allow "Install unknown apps" if asked).

NPC EDITOR (inside the game): Menu -> NPC EDITOR.
 ADD PHOTO picks pictures from your gallery/camera. Edit size, flip, mark one as BOSS,
 replace or delete. Select PLAYER to give your own character a photo.
 Photos are saved on the device. Cut-out PNGs (transparent background) look best.
